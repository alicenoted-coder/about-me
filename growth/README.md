# 我的成長軌跡

記錄自己「有所成長」的時間點與事件。

## 怎麼記錄

1. 複製 [`TEMPLATE.md`](TEMPLATE.md)，命名為 `YYYY-MM-DD-簡短名稱.md`（例如 `2026-11-15-第一次公開演講.md`）
2. 填寫內容——**只有「發生了什麼事」和「之前 → 之後」是必填**，其他想到再補
3. 在下方時間軸加一行，新的放最上面

> 小提醒：不用等到「大事」才記。第一次敢開口問問題、終於搞懂一個概念、用新方法處理舊問題，都算。
